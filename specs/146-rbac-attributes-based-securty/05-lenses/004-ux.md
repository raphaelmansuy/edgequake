# Lens — UX (SPEC-146)

## Outcome

Users never learn unauthorized documents exist. Operators can label and manage access without reading Cedar. Quarantine and break-glass are honest, distinct journeys.

## Empty states (normative — from zz-raw UX lock)

```ascii
  Zero authorized hits
  ┌────────────────────────────────────────┐
  │  No matching results.                  │
  │  Try different terms or filters.       │
  │                                        │
  │  ✗ never: "some results hidden"        │
  │  ✗ never: "0 of N authorized"          │
  │  ✗ never: count badges implying withholds │
  └────────────────────────────────────────┘

  Zero-authz ≡ true-empty for query / search / browse.
```

## 404 vs 403

| Case | HTTP | UI copy |
|------|------|---------|
| Unauthorized doc/chunk/graph id | 404 | “Document not found” |
| Cannot ingest / manage policy / manage members | 403 | Capability message (no existence leak) |
| Break-glass required | 403 + banner | Explicit break-glass journey |

## Citations

- Only post-PDP authorized chunks.  
- Drop unauthorized cites entirely — no greyed “Restricted”, no truncated title, no path.  
- Prefer omit over “Source unavailable” if id could be enumerated.

## Upload labeling

```ascii
  Dropzone / Upload dialog
  ├── Parser / Vision (existing)
  └── Security
      ├── Classification   [select]
      ├── Share mode       [Workspace | ACL | Classified | Owner only]
      ├── Project          [select/create]
      ├── PII / Export     [toggles]
      └── ACL members      (visible iff share_mode=acl)

  Workspace default share_mode=workspace → Security collapsed (Advanced)
  Workspace default classified → Security required before Admit
```

## Quarantine

```ascii
  Status chip: Labeling failed / Quarantined
  Message: "Security labels could not be applied.
            This document isn’t searchable until labeling succeeds."
  Actions: [Retry labels]  (editors)
  ✗ No PDP/policy internals in copy
  ✗ Never show as Completed / query_ready
```

## Settings IA

```ascii
  Settings
  ├── Users (global)     existing UserManagementCard — fixed role labels
  ├── Workspace members  NEW
  ├── Roles              NEW
  ├── Attributes         NEW
  ├── Policies           NEW (templates + advanced)
  └── Audit / Break-glass NEW (admin)
```

## Query / graph UX

- Document picker autocomplete = authorized set only.  
- Graph neighborhood = authorized occurrences; no unauthorized degree badges.  
- SSE: never stream denied titles then redact.

## A11y

- Security fields labeled; errors associated with inputs.  
- Classification chips have text, not color-only.  
- Break-glass banner `role="alert"`.
