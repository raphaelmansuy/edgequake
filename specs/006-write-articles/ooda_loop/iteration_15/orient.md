# Orient Phase - Iteration 15: Future Roadmap

## Target Audiences

### 1. Current Users

- **Interest**: What's coming next? Should I invest more in EdgeQuake?
- **Pain Point**: Uncertainty about project longevity and feature trajectory
- **Hook**: "Here's the roadmap—we're building for the long term"

### 2. Potential Users Evaluating

- **Interest**: Will EdgeQuake meet my future needs?
- **Pain Point**: Don't want to adopt something that stagnates
- **Hook**: "Planned integrations with LangChain, Python SDK, SSO"

### 3. Contributors

- **Interest**: Where can I help? What's the vision?
- **Pain Point**: Don't know where to start
- **Hook**: "Good first issues and high-impact contribution areas"

### 4. Technical Decision Makers

- **Interest**: Enterprise features, compliance, support
- **Pain Point**: Need SSO, RBAC, audit logs for enterprise adoption
- **Hook**: "Enterprise roadmap: SSO, compliance, support SLAs"

## Positioning Strategy

### Angle: "Building the Future of Graph-RAG"

EdgeQuake isn't just a tool—it's a platform. The roadmap shows:

1. **Breadth**: More LLM providers, more storage backends, more document formats
2. **Depth**: Better query capabilities, graph enhancements, AI agents
3. **Enterprise**: SSO, RBAC, compliance, support
4. **Community**: SDKs, integrations, contribution pathways

**Message**: "EdgeQuake is a living project with a clear vision and active development."

### Roadmap Categories

| Category           | Priority | Timeline   |
| ------------------ | -------- | ---------- |
| LLM Providers      | High     | Q1 2025    |
| Python SDK         | High     | Q1 2025    |
| SSO/RBAC           | High     | Q2 2025    |
| Document Formats   | Medium   | Q2 2025    |
| Graph Enhancements | Medium   | Q3 2025    |
| AI Agents          | Medium   | Q3-Q4 2025 |
| Mobile App         | Low      | 2026       |

### Transparency Principle

Be honest about:

- What's planned vs. what's aspirational
- No guaranteed timelines (plans change)
- Community input shapes priorities
- Some features need funding/resources
