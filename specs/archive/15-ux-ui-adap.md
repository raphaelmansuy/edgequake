# UX/UI Audit Prompt (Improved & Precision-Focused)

You are a **senior UX/UI designer and product design auditor** specializing in **slick, modern interfaces**.

We have documented the UI/UX of a web application called **EdgeQuake WebUI**. The documentation is organized in the `ux_ui_map/` directory.

Now we want to draft an improvement plan for the UX/UI of EdgeQuake WebUI based on the existing documentation to make the interface more user-friendly, intuitive, and visually appealing while adhering to modern design principles of SLICKness and MINIMALISM.

## Your Task

1. Propose a solution to move the MultiTenant container from the Left Navigation to the header bar, ensuring it remains easily accessible without cluttering the interface.

2. For the Graph page, ensure node detail display are fully integrated into the detail panel on the right side of the screen, avoiding any pop-up modals that disrupt user flow. Be careful to maintain clarity and usability in the detail panel. Study the scroll behavior and ensure that all information is easily accessible without overwhelming the user. Ensure the Right Detail Panel is well-organized and intuitive and must be resizable.

3. Study how to make each header bar more compact while retaining all essential functionality. Propose specific changes to reduce height, padding, or margins without sacrificing usability.

4. Study in depth each container and define what is fixed vs scrollable. Propose changes to improve the user experience when dealing with long lists or content overflow, ensuring that important information remains accessible.

4. Study in detail the padding and margin usage across all components. Propose adjustments to create a more cohesive and visually appealing layout that enhances readability and user engagement. Study with greet care each input field, button, and interactive element to ensure they are optimally spaced for both aesthetics and usability.

## Process

Use ux_ui_map/ as a Map to understand the current UX/UI structure of EdgeQuake WebUI. 

Write all your analysis and proposals in a structured in simple markdown actionable document in ./ux_ui_improvement_plan/ directory. Ensure to cross map your proposals with the existing documentation in ux_ui_map/ for clarity and existing code references or screenshots. 

While working on this task, adhere to the following principles:

- Use a scratchpad approach: document your observations, ideas, and reasoning as you analyze the existing UX/UI documentation, use scratchpad as append only log to keep track of your thought process.
- Be precise and concise: focus on delivering clear, actionable recommendations without unnecessary verbosity.
- Prioritize user experience: ensure that all proposed changes enhance the overall usability and accessibility of the application.
- Maintain a plan of all your action in ./ux_ui_improvement_plan/actions.md as you progress through the task.
- Maintain visual appeal: ensure that the proposed designs are not only functional but also aesthetically pleasing
- Align with modern design principles: ensure that all recommendations adhere to contemporary UX/UI best practices, emphasizing SLICKness and MINIMALISM.
