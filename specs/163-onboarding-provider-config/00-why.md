# 00 — Why

A newcomer cannot configure EdgeQuake without reading three env files, guessing which of seven install paths is current, and hoping `/health` is telling the truth. Local servers (oMLX, MLX-LM, llama.cpp, vLLM-MLX) exist in the catalog but have no operator path. API keys cannot be stored per workspace. Health lies.

SPEC-163 exists so the first hour with the repo produces a working Graph-RAG, with honest diagnostics and production-safe defaults that are opt-in rather than accidental.
