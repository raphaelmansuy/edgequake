## 1. Overview

This document specifies search indexing, site-wide navigation, and SEO configuration for the unified Astro + Starlight site. Starlight provides built-in Pagefind search for docs; this spec addresses extending search to marketing pages, configuring navigation, and achieving strong SEO.

---

## 2. Search Architecture

```
+---------------------------+
| Starlight Docs (52 pages) |----> Automatically indexed by Pagefind
+---------------------------+      (built into Starlight build)
                                       |
+---------------------------+          |
| Marketing Pages (7 pages) |----> Opt-in indexing via          +----------+
+---------------------------+      data-pagefind-body  -------> | Pagefind |
                                                                | Index    |
                                                                +----+-----+
                                                                     |
                                                   +-----------------v------+
                                                   | Search UI Component    |
                                                   | (Starlight search bar) |
                                                   +-----------------------+
```

### 2.1 Pagefind Integration

Starlight runs Pagefind automatically at build time. All docs pages are indexed by default.

### 2.2 Marketing Page Indexing

Marketing pages are not Starlight pages and thus not indexed by default. To include them, add `data-pagefind-body` to the main content area:

```astro
<!-- src/pages/demo.astro -->
<MarketingLayout title="Demo">
  <main data-pagefind-body>
    <h1>Demo</h1>
    <!-- Content here will be indexed by Pagefind -->
  </main>
</MarketingLayout>
```

### 2.3 Exclusions

Exclude boilerplate (header, footer, nav) from search:

```astro
<header data-pagefind-ignore>
  <!-- Not indexed -->
</header>
```

## 3. Navigation Structure

### 3.1 Global Header

The global header appears on all pages (marketing + docs).

```
+--------------------------------------------------------------+
| [Logo] EdgeQuake   Home  Docs  Demo  Ecosystem  Enterprise   |
|                                          [Search] [Theme]    |
+--------------------------------------------------------------+
```

#### Implementation

On **marketing pages**, this is a custom `<Header />` Astro component.

On **docs pages**, Starlight renders its own header. Override the header component via `components` config in `astro.config.mjs`:

```javascript
starlight({
  components: {
    SiteTitle: "./src/components/overrides/SiteTitle.astro",
    // Add marketing links to Starlight header
    Header: "./src/components/overrides/Header.astro",
  },
});
```

## 4. SEO Configuration

### 4.1 Meta Tags

Each page needs:

```html
<title>{page.title} | EdgeQuake</title>
<meta name="description" content="{page.description}" />
<link rel="canonical" href="https://edgequake.com{page.url}" />
```

**Starlight docs pages** get this automatically from frontmatter:

```yaml
---
title: Installation
description: How to install and set up EdgeQuake
---
```

**Marketing pages** set meta explicitly in the layout:

```astro
---
// src/pages/demo.astro
const title = "Demo | EdgeQuake";
const description = "Try EdgeQuake's Graph RAG pipeline with interactive demos.";
---
<html>
<head>
  <title>{title}</title>
  <meta name="description" content={description} />
  <link rel="canonical" href="https://edgequake.com/demo/" />
</head>
```

### 4.2 OpenGraph & Twitter Cards

```astro
<!-- Marketing layout head -->
<meta property="og:title" content={title} />
<meta property="og:description" content={description} />
<meta property="og:type" content="website" />
<meta property="og:url" content={`https://edgequake.com${Astro.url.pathname}`} />
<meta property="og:image" content="https://edgequake.com/og-image.png" />
<meta property="og:site_name" content="EdgeQuake" />

<meta name="twitter:card" content="summary_large_image" />
<meta name="twitter:title" content={title} />
<meta name="twitter:description" content={description} />
<meta name="twitter:image" content="https://edgequake.com/og-image.png" />
```

Starlight docs pages: configure `head` in `astro.config.mjs`:

```javascript
starlight({
  head: [
    {
      tag: "meta",
      attrs: {
        property: "og:image",
        content: "https://edgequake.com/og-image.png",
      },
    },
    {
      tag: "meta",
      attrs: { property: "og:site_name", content: "EdgeQuake" },
    },
  ],
});
```

### 4.3 Sitemap

Astro's `@astrojs/sitemap` generates `sitemap-index.xml` automatically.

```javascript
// astro.config.mjs
import sitemap from "@astrojs/sitemap";

export default defineConfig({
  site: "https://edgequake.com",
  integrations: [sitemap()],
});
```

Output: `dist/sitemap-index.xml` referencing sub-sitemaps for all pages.

### 4.4 Structured Data (JSON-LD)

Add to the home page for rich search results:

```astro
<script type="application/ld+json" set:html={JSON.stringify({
  "@context": "https://schema.org",
  "@type": "SoftwareApplication",
  "name": "EdgeQuake",
  "applicationCategory": "DeveloperApplication",
  "description": "Advanced Graph RAG framework in Rust for knowledge-augmented generation",
  "url": "https://edgequake.com",
  "operatingSystem": "Cross-platform",
  "offers": {
    "@type": "Offer",
    "price": "0",
    "priceCurrency": "USD"
  }
})} />
```

### 4.5 robots.txt

```
# public/robots.txt
User-agent: *
Allow: /
Sitemap: https://edgequake.com/sitemap-index.xml

# Exclude Pagefind internals
Disallow: /pagefind/
```
