# Analysis - Iteration 19

## Gap: No user-facing tutorial for lineage tracing

Users need a step-by-step guide showing the practical workflow of tracing entities to sources.

## Approach

6-step tutorial walking through the full traceability chain:
1. Find an entity (WebUI or API)
2. Get entity provenance
3. Trace to source chunk
4. Get full chunk lineage
5. View complete document lineage
6. Get document metadata

Each step includes curl, SDK (Rust/TS/Python), and WebUI approaches.
