# OODA Iteration 06 - Orient

**Date**: 2025-01-XX
**Focus**: Query Modes Deep-Dive Documentation

## 🧭 Orientation

### 1. Target Audience

| Audience         | Needs                                             |
| ---------------- | ------------------------------------------------- |
| Developers       | When to use each mode, API parameters             |
| Data scientists  | Algorithm details, scoring mechanisms             |
| Product managers | Trade-off understanding, performance expectations |
| DevOps           | Resource implications, tuning parameters          |

### 2. Content Strategy

Create a comprehensive guide that:

1. Explains the theory behind each mode
2. Provides decision flowchart for mode selection
3. Shows real-world examples with queries and responses
4. Documents performance characteristics
5. Includes tuning recommendations

### 3. Diagram Requirements

- Mode selection flowchart (ASCII)
- Query execution state machine per mode
- Context building visualization
- Performance comparison table

### 4. Example Queries Needed

For each mode, provide:

- Example question that works best
- Why that mode is appropriate
- Expected context structure
- Sample response quality
