# What this is

EdgeQuake turns your files into a map, then answers questions from that map and shows where each part of the answer came from.

You use it in a web browser. The public example is [https://demo.edgequake.com/](https://demo.edgequake.com/). After you [sign in](02-sign-in-and-getting-around.md), the left sidebar is the whole product:

- **Dashboard** is the home page. It shows how many files and map items you have.
- **Documents** is the file list. You drop PDFs here.
- **Query** is where you ask a question in a box and read the answer.
- **Knowledge Graph** is the map itself: dots and lines you can click.
- **Knowledge** is where you type extra notes, such as a glossary, that the map should also know.
- **Workspace** is the settings for one collection of files: which model reads them, and how they are split.
- **Pipeline** is the work queue. It shows files waiting, files being read, and files that finished.
- **Costs** is the bill for the model calls in this collection.
- **API Explorer** is the same product written as web requests, for people who want a program to talk to it.
- **Settings** is your own look and feel, plus the connections to model providers.

The header, on every page, shows which organization and which workspace you are in. On the demo that line reads **Default — Default Workspace**. The green dot and **API v0.36.0** mean the server behind the page is up. The pictures in this tour were taken there. The screens themselves are the same in the release that ships this tour.

A typical visit is short. You look at the [Dashboard](03-dashboard.md), open a file under [Documents](04-documents.md), ask something on [Query](06-ask-a-question.md), then click a dot on [the map](07-the-map.md) to see why the answer mentioned that name.
