# Benchmark 002 — `DATA-PGVEC-VECTORS-ANN-QUERY-FILTERED-002`

This page covers vector search with metadata filters, the ANN query behind `VectorStorage::query_filtered`. It gives the cost to expect and the plan to check. It is a template, so it holds no measured timings.

> **Plan template, not a measurement.** The test harness can append a real plan under "Captured EXPLAIN" (see the [README](./README.md)).

| Item | Value |
|------|-------|
| Engine | PGVEC (pgvector) |
| Entry point | `VectorStorage::query_filtered` |
| Source | `edgequake/crates/edgequake-storage/src/adapters/postgres/vector/storage_impl.rs` |
| Expected time | O(ef * log N) with the ANN index; O(N) if the plan is a sequential scan |
| Pass rule | The plan uses the ANN index. A plain Seq Scan on a large table fails the test |

## Complexity

- Variables: N = rows, K = top_k, D = dim, ef = ef_search
- Time: O(ef * log N) expected with ANN; worst case O(N) if the plan scans sequentially
- Space: O(K + ef)
- I/O: about O(ef) random pages; index residency is critical
