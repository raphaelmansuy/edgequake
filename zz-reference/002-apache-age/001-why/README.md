# `001-why/` — Why Apache AGE

See [001-five-whys.md](001-five-whys.md) for the full reasoning chain.

TL;DR:

> EdgeQuake's graph (entities + relationships extracted from documents) is
> the same data as the documents/chunks already in Postgres. AGE lets you
> express graph traversals in Cypher *and* join them with SQL — without
> moving data into Neo4j.
