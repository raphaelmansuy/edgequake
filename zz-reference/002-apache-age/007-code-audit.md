# Code Audit — Apache AGE features used by EdgeQuake but not yet documented

> Cross-referenced against [Apache AGE master (v1.7.0)](https://github.com/apache/age)
> (cloned at `/tmp/zzref/age` for verification) and the EdgeQuake
> `edgequake-storage` crate.

This file lists facts that exist in **code** (either AGE upstream or
EdgeQuake adapters and migrations) but were under-documented in the other
files of this folder.

## 1. Upstream AGE surface we under-document

| Feature                                                                                                                                                                                                                                        | Upstream source                                                                                                                                            | Why it matters                                                                                                                                                                          |
| ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `graphid` type encodes `(label_id, entry_id)` and has full btree ops                                                                                                                                                                           | [`sql/age_main.sql:153-351`](https://github.com/apache/age/blob/master/sql/age_main.sql)                                                                   | Explains why edge `start_id`/`end_id` are joinable by `=` in raw SQL                                                                                                                    |
| `_ag_label_vertex` schema = `(id graphid, properties agtype)`; `_ag_label_edge` adds `start_id graphid, end_id graphid`                                                                                                                        | [`src/include/commands/label_commands.h:26-27`](https://github.com/apache/age/blob/master/src/include/commands/label_commands.h) + label catalog migration | Lets you write the exact SQL that EdgeQuake uses for sweep reads                                                                                                                        |
| `ag_catalog.agtype_to_json(value)` → returns `json`                                                                                                                                                                                            | [`sql/agtype_coercions.sql:166`](https://github.com/apache/age/blob/master/sql/agtype_coercions.sql)                                                       | Canonical way to extract scalar props from `agtype`                                                                                                                                     |
| `ag_catalog.agtype_to_jsonb(value)` → returns `jsonb` via `agtype_to_json($1)::jsonb`                                                                                                                                                          | `sql/agtype_coercions.sql:181-187`                                                                                                                         | Needed for `jsonb` operators like `@>`, `?`, `?&`                                                                                                                                       |
| `ag_catalog.jsonb_to_agtype(jsonb)`                                                                                                                                                                                                            | `sql/agtype_coercions.sql:193`                                                                                                                             | Round-trip for parameter passing from app code                                                                                                                                          |
| `ag_catalog.agtype_access_operator(VARIADIC agtype[])`                                                                                                                                                                                         | [`sql/agtype_access.sql:149`](https://github.com/apache/age/blob/master/sql/agtype_access.sql)                                                             | The underlying primitive for `agtype -> 'key'`; EdgeQuake uses it directly at [`graph/mod.rs:494, 542`](../../../edgequake/crates/edgequake-storage/src/adapters/postgres/graph/mod.rs) |
| `ag_catalog.create_graph(name name)` / `drop_graph(name, cascade bool=false)` / `create_vlabel(graph cstring, label cstring)` / `create_elabel(graph cstring, label cstring)` / `drop_label(graph name, label name, ...)` / `alter_graph(...)` | [`sql/age_main.sql:93-119`](https://github.com/apache/age/blob/master/sql/age_main.sql)                                                                    | Full graph DDL surface                                                                                                                                                                  |
| `ag_catalog.load_labels_from_file(graph, label, file_path)` and `load_edges_from_file(...)`                                                                                                                                                    | `sql/age_main.sql:129-138`                                                                                                                                 | Bulk-load path; faster than per-vertex `MERGE` for cold ingest                                                                                                                          |
| `agtype` equality / ordering operators (`=`, `<>`, `<`, `>`, `<=`, `>=`)                                                                                                                                                                       | `sql/age_main.sql:209-301`                                                                                                                                 | Means you can `WHERE properties = '{"node_id":"X"}'::agtype` without a function call                                                                                                    |
| Per-graph schema mirrors the graph name 1-for-1 (`SELECT create_graph('edgequake')` → schema `edgequake`)                                                                                                                                      | `sql/age_main.sql:93`, AGE manual "Graph Objects"                                                                                                          | Justifies `edgequake."_ag_label_vertex"` as a stable address                                                                                                                            |

## 2. EdgeQuake patterns built on top of AGE (not in this folder yet)

| Pattern                                                                                                                                                                       | Where it lives                                                                                                    | Note                                                                                                                                                        |
| ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Force `search_path = public` on every pooled connection** unless AGE is needed                                                                                              | [`connection.rs:73-86`](../../../edgequake/crates/edgequake-storage/src/adapters/postgres/connection.rs)          | Prevents `"$user"` resolving into the `edgequake` graph schema and shadowing public tables                                                                  |
| **Idempotent extension bootstrap** (`CREATE EXTENSION IF NOT EXISTS age CASCADE`) followed by per-connection `LOAD 'age'` is implicit (extension load on first cypher() call) | [`connection.rs:136-156`](../../../edgequake/crates/edgequake-storage/src/adapters/postgres/connection.rs)        | The bootstrap also calls `SET search_path = ag_catalog, "$user", public` and immediately resets — proves the connection is AGE-capable without polluting it |
| **`is_age_available()` SQL function** for graceful fallback                                                                                                                   | [`migrations/013_add_age_graph.sql:74`](../../../edgequake/migrations/013_add_age_graph.sql)                      | Allows the adapter to fall back to SQL tables if AGE isn't installed                                                                                        |
| **Fast graph stats via `pg_inherits + pg_class.reltuples`** instead of `MATCH (n) RETURN count(n)`                                                                            | [`graph/mod.rs:156-160`](../../../edgequake/crates/edgequake-storage/src/adapters/postgres/graph/mod.rs)          | O(1) estimate; avoids Cypher overhead for dashboards                                                                                                        |
| **Batched degree query** with `WITH input(v, ord) AS (SELECT v, ord FROM unnest($1::text[]) WITH ORDINALITY)`                                                                 | [`graph/mod.rs:485-494`](../../../edgequake/crates/edgequake-storage/src/adapters/postgres/graph/mod.rs)          | Pass a Postgres array into the agtype world; preserves caller order via `WITH ORDINALITY`                                                                   |
| **`(to_json(v)::text)::agtype` text→agtype coercion**                                                                                                                         | [`graph/mod.rs:489, 537, 603`](../../../edgequake/crates/edgequake-storage/src/adapters/postgres/graph/mod.rs)    | Cheaper than `jsonb_to_agtype(to_jsonb(...))`; works for scalars and small objects                                                                          |
| **SQL-only edge fetch** joining on `start_id`/`end_id` graphid equality                                                                                                       | [`graph/mod.rs:546-551`](../../../edgequake/crates/edgequake-storage/src/adapters/postgres/graph/mod.rs)          | Bypasses Cypher when reading many edges by source/target                                                                                                    |
| **Expression GIN/B-tree indexes on `agtype_to_json(properties)->>'key'`** for `tenant_id`, `workspace_id`, `entity_type`, `node_id`                                           | [`migrations/014_add_graph_indexes.sql`](../../../edgequake/migrations/014_add_graph_indexes.sql)                 | Without these, every `MATCH (n:Node {node_id:'…'})` becomes a seq-scan                                                                                      |
| **Same pattern on edges** for `source_id`/`target_id`                                                                                                                         | [`migrations/036_add_edge_property_indexes.sql`](../../../edgequake/migrations/036_add_edge_property_indexes.sql) | Reduces `get_edges_for_node_set` from `O(N_edges)` to `O(matches)`                                                                                          |
| **`pg_trgm` + `to_tsvector('english', properties->>'node_id')`** GIN index                                                                                                    | [`migrations/015_add_fulltext_search.sql`](../../../edgequake/migrations/015_add_fulltext_search.sql)             | Enables fuzzy entity-name search inside the AGE graph                                                                                                       |
| **MERGE upsert idiom** `MERGE (n:Node {node_id: 'X'}) SET n = { ... }`                                                                                                        | [`graph/mod.rs:263`](../../../edgequake/crates/edgequake-storage/src/adapters/postgres/graph/mod.rs)              | Idempotent — replaces all properties; not a partial update                                                                                                  |
| **DETACH DELETE for cascade**                                                                                                                                                 | [`graph/mod.rs:286`](../../../edgequake/crates/edgequake-storage/src/adapters/postgres/graph/mod.rs)              | Removes the node and all incident edges in one Cypher statement                                                                                             |

## 3. What AGE source to read next if a contributor wants more

- [`sql/age_main.sql`](https://github.com/apache/age/blob/master/sql/age_main.sql) — the **only** authoritative list of `ag_catalog` functions, operators, and the `graphid` type.
- [`sql/agtype_access.sql`](https://github.com/apache/age/blob/master/sql/agtype_access.sql) — the `agtype_access_operator` and the chain operator semantics. Required if you write raw SQL against vertex properties.
- [`sql/agtype_coercions.sql`](https://github.com/apache/age/blob/master/sql/agtype_coercions.sql) — every `agtype ↔ json/jsonb/text` cast.
- [`sql/agtype_operators.sql`](https://github.com/apache/age/blob/master/sql/agtype_operators.sql) — agtype arithmetic and containment operators (`@>`, `->>`, etc.) — used in Cypher's `WHERE`.
- [`src/include/commands/label_commands.h`](https://github.com/apache/age/blob/master/src/include/commands/label_commands.h) — the literal table-name constants (`_ag_label_vertex`, `_ag_label_edge`).
- [`src/backend/utils/adt/agtype.c`](https://github.com/apache/age/blob/master/src/backend/utils/adt/agtype.c) — agtype value model implementation; useful when debugging serialization edge cases.
- [AGE manual → clauses](https://age.apache.org/age-manual/master/clauses.html) — authoritative list of supported Cypher clauses (use before assuming `WITH`, `OPTIONAL MATCH`, `UNWIND` work — they do, but check version).
