# Task Log - Fix 5 Issues in EdgeQuake WebUI

Date: 2025-12-23 12:10  
Mode: beastmode

## Actions

1. **Fixed query conversation state persistence**

   - Added `ChatMessage` interface to `use-query-store.ts`
   - Added `conversationMessages` state with persist middleware
   - Added actions: `setConversationMessages`, `addConversationMessage`, `updateConversationMessage`, `clearConversation`
   - Updated `query-interface.tsx` to use store instead of local useState

2. **Fixed markdown-renderer 'children' error**

   - Updated `parseCOTContent` in `thinking-display.tsx` to handle undefined/null content
   - Added streaming fallback in `markdown-renderer.tsx` - renders plain text during streaming to avoid react-markdown parsing errors

3. **Fixed document title display**

   - Modified backend `documents.rs` to store document metadata with title
   - Updated `list_documents` to retrieve titles from metadata storage
   - Title now properly displays in document table as filename

4. **Fixed NodeDetails panel reopening UX**

   - Added `showNodeDetails` boolean to graph store
   - Added `toggleNodeDetails` action
   - Updated `graph-viewer.tsx` to show "Show Node Details" button when panel is hidden
   - X button now toggles visibility instead of clearing selection

5. **Implemented async upload/processing pipeline**
   - Added `async_processing` option to `UploadDocumentRequest`
   - When enabled, upload returns immediately with `task_id`
   - Background worker processes document via existing task queue system
   - Updated frontend to use async processing by default

## Decisions

- Used existing task queue infrastructure from `edgequake-tasks` crate
- Backwards compatible: sync processing still works when `async_processing: false`
- Store document content in KV storage for background processing
- Simple toggle pattern for NodeDetails panel UX
