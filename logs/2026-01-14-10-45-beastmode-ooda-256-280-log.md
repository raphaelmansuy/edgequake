## Lessons/Insights

1. **Multi-Tenant Bug**: Original `clear()` implementation was NOT workspace-scoped, causing cross-tenant data loss in production
2. **Trait Extensibility**: Default trait implementations allow gradual rollout without breaking existing code
3. **Metadata Design**: Storing workspace_id in metadata JSONB enables powerful filtering without schema changes
4. **PostgreSQL JSONB**: `metadata->>'workspace_id'` query is efficient with proper indexing
5. **Apache AGE Cypher**: Cypher WHERE clauses support property filtering (n.workspace_id)
6. **Memory Storage**: HashMap filtering is O(n) but fast enough for typical workspaces
7. **Graph + Vector Clearing**: Must clear BOTH when LLM changes (chunks may differ)
8. **Embedding-Only Clearing**: Can preserve graph when only embedding model changes
