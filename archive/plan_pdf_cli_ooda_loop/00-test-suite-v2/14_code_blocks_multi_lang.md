# Code Blocks

## Python

```python
def hello(name: str) -> str:
    return f"Hello, {name}!"

if __name__ == "__main__":
    print(hello("World"))
```

## JavaScript

```javascript
function greet(name) {
    return `Hello, ${name}!`;
}

console.log(greet("World"));
```

## Rust

```rust
fn main() {
    let name = "World";
    println!("Hello, {}!", name);
}
```

## SQL

```sql
SELECT name, age
FROM users
WHERE age > 21
ORDER BY name;
```
