# Test Document for EdgeQuake

## Overview

This is a test document to verify the document ingestion pipeline. EdgeQuake is a powerful knowledge graph RAG framework built in Rust.

## Key Features

- **Entity Extraction**: Automatically identifies and extracts entities from documents
- **Relationship Mapping**: Creates meaningful connections between entities
- **Vector Embeddings**: Generates embeddings for semantic search
- **Graph Storage**: Stores knowledge in a graph database

## Technical Details

EdgeQuake uses a 6-phase pipeline for document processing:

1. **Upload Phase**: Document is uploaded to the system
2. **Conversion Phase**: PDF documents are converted to Markdown
3. **Chunking Phase**: Document is split into processable chunks
4. **Extraction Phase**: Entities and relationships are extracted
5. **Embedding Phase**: Vector embeddings are generated
6. **Storage Phase**: Knowledge is stored in the graph

## Conclusion

This test document demonstrates the ingestion pipeline functionality. EdgeQuake provides a unified approach to document processing.
